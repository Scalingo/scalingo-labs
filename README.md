# scalingo-labs

> ⚠️ **Disclaimer**: The content of this repository is **not officially supported by Scalingo**. It is provided as-is for demonstration and experimental purposes by the Scalingo DevRel & Revenue team.

This repository hosts demos and experimental projects produced by the Scalingo DevRel & Revenue team.

## Structure

Each top-level folder corresponds to one DevRel / Revenue project.

Buildpacks and other standalone deliverables produced by this team use the `scalingo-labs-` prefix (e.g. `scalingo-labs-postgrest`).

## Contributing

All Scalingo developers are welcome to contribute. Open a pull request — at least one review is required before merging.
